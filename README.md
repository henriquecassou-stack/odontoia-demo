# OdontoIA · demonstração

Sistema para clínicas odontológicas com recepcionista de IA no WhatsApp, agenda por dentista,
Equipe de IA (confirmações, retornos, cobranças e orçamentos), odontograma e financeiro.

**Acesse:** https://henriquecassou-stack.github.io/odontoia-demo/

Esta é uma versão de demonstração: roda inteira no navegador, com dados fictícios que ficam só no
aparelho de quem acessa. Entre com qualquer senha.
